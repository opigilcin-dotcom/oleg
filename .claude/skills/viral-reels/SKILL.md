# Viral Reels — проектный плейбук

Перед работой прочитай `plati-po-miru/1-КАНОНЫ-и-ПАСПОРТА.md` (каноны, паспорта аккаунтов) и,
если задача про сетку Instagram, `plati-po-miru/СЕТКА-Instagram.md`.

## 1. Что ранжирует ролик (2026)
- Платформы смотрят на **досмотр + пересмотр + отправки (shares/DM)**. На Instagram отправка в директ — главный рычаг охвата не-подписчиков; лайки слабее.
- Shorts и длинные видео ранжируются разными системами; у Shorts решает удержание и «удовлетворённость» (лайки/комменты/репосты).
- Оригинальность: перезаливы, водяные знаки, почти-дубли режутся. Каждому аккаунту — свои персонаж/голос/палитра.
- Отсюда правила монтажа: хук ≤1 с, смена плана каждые 1,5–3 с, полоса прогресса, петля в конце, триггер «сохрани/отправь другу».

## 2. Каноны ролика (чек-лист)
1. **Хук 0–2 с:** картинка + текст (≤7 слов, заглавные) + первая фраза говорят одно и то же. Первый кадр уже содержит действие.
2. **Формулы хука, подтверждённые выбросами в нише (RU, 2026):** «Выключи это…», «X может то, чего ты не знал», «Почему не работает…», «Вот как нас обманывают…», «Халява/скидки», «Новость-паника», «Совет-приказ», «Как сделать X в стране Y».
3. **Тело:** одна мысль, 20–35 с, открытая петля («третий способ — самый рабочий»), субтитры по словам с подсветкой.
4. **Финал:** один CTA, петля к первому кадру, текстовый триггер сохранения/репоста.
5. **Две концовки:** Instagram — без бренда/промокода (реклама на ресурсах Meta в РФ запрещена с 01.09.2025) → «гайд в Telegram». TikTok/Shorts — бренд + промокод + «Реклама» + erid.
6. **Нельзя:** «обход санкций/блокировок», чужие кадры из фильмов, обещания «без комиссии / работает везде», выдуманные списания/отказы банков, имитация голоса автора, неподтверждённые «сама пользуюсь».

## 3. Данные ниши (оффер)
- Сервис на официальном сайте называется **«Плати по всему миру»** (platipomiru.com). Для ChatGPT — карта **«Для подписок»** (USD, 2 990 ₽). Скриншоты снимать с сайта (страница `/online-service/chatgpt/`, блок карты на главной), cookie-баннер закрывать «Отклонить необязательные».
- Промокод партнёра: **LEO500** (скидка 500 ₽ — со слов партнёра, на сайте не опубликовано; формулировать осторожно).
- Спрос (YouTube-поиск, RU): «как оплатить чат gpt в россии» ~80k/мес, «как пополнить app store в россии» ~18k (+57%), «как оплатить ps plus» ~9k при конкуренции 8/100.
- Прямые рекламные Shorts «как оплатить» у конкурентов набирают 0–1000 просмотров; миллионы в Reels/TikTok — у сюжетных/развлекательных обёрток, где продукт появляется на 70–80% ролика.

## 5. Подводные камни окружения (важно)
- Этот контейнер **не видит** cloudfront/upload.higgsfield.ai (403 от прокси). Скачивание, рендер и загрузку делать в **песочнице Higgsfield** (`sandbox_exec`): там ffmpeg, sox, faster-whisper, Montserrat, Node, интернет.
- Песочница живёт ~10 с после вызова. Сначала запусти «держатель» `sleep 890` с `background:true` (лиза 15 мин), долгие шаги — тоже `background:true`, потом опрашивай лог.
- Файлы в песочницу — только **текстом через heredoc** (один файл на вызов, команда ≤16 000 символов). Base64-архивы песочница отклоняет.
- Результат наружу: `media_upload` → в той же команде `curl -X PUT -H "Content-Type: …" -H "If-None-Match: *" --upload-file …` → `media_confirm`. Ссылку отдавать пользователю.
- Remotion: полному Chromium нужен headless shell — в песочнице `npx remotion browser ensure`, локально `--browser-executable` на `/opt/pw-browsers/chromium_headless_shell-*/…/headless_shell`. Локально удобно гонять `remotion still` на заглушках для проверки раскладки до рендера.
- Скриншоты сайтов — `playwright-core` в песочнице (`chromium.launch()` без пути), мобильный вьюпорт 432×768 @2.5x = 1080 px по ширине.

## 5a. Посмотреть чужой ролик (разбор конкурента/выброса)
- Навык `watch` (`.claude/skills/watch`): `python3 .claude/skills/watch/scripts/watch.py "<URL>" --engine local --question "<вопрос>"` — кадры + расшифровка. Нужны ffmpeg и yt-dlp (`pip install --user "yt-dlp[default]"`).
- В облачном контейнере YouTube/Instagram/TikTok могут быть закрыты сетевой политикой (403 от прокси) — тогда смотреть через `vidiq_video_watch`, `vidiq_watch_shortform_content`, `NexLev watch_youtube_video_and_ask` / `watch_instagram_video_and_ask` / `watch_tiktok_video_and_ask`.

## 6. Контроль качества перед выдачей
- `ffprobe`: 1080×1920, 30 fps, нужное число кадров, h264 + aac; громкость `loudnorm` ≈ −14 LUFS.
- Контакт-лист 6–12 кадров по всем сценам → посмотреть глазами: текст не обрезан, слова не слипаются, ничего важного не под UI (верх ~150 px, низ ~350 px), промокод целиком виден весь финал.
- Сюжет понятен без звука (все реплики продублированы текстом).
- Маркировка рекламы (рекламодатель + erid) — для рекламных версий; если нет — явно сказать пользователю.
