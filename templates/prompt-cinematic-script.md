## ШАГ 1. АНАЛИЗ ЭТАЛОНА (вывести перед сценарием, 10–12 строк)
Если эталон дан — разбери его кратко:
- **Хук (0–10 сек):** как удерживается внимание в первых фразах.
- **Структура пункта:** крючок-факт → подъём (даты/цифры/имена) → причина гибели → жуткий остаток сегодня → мост к следующему.
- **Стиль:** обращение на «ты», риторические вопросы, плотность конкретики (годы, числа, имена, места).
- **Скорость:** слов/сек, чередование длинных и коротких фраз.
- **Вовлечение:** клиффхэнгеры-мосты, отложенная интрига №1, врезки CTA.
- **Хронометраж и плотность фактов.**
Если эталона нет — пропусти и опиши целевой стиль в 3–4 строках.

## ШАГ 2. ПРОВЕРКА ФАКТОВ (обязательно)
Это документалка, наш edge — точность. Перед написанием:
- Подбери реальные объекты по теме с задокументированной историей (если факты не даны — найди и сверь).
- Для каждого пункта: один проверяемый «крючковый» факт + один неожиданный достоверный детайл.
- Всё спорное/легендарное помечай инлайн `[VERIFY]` и подавай как «по легенде, которую рассказывают местные».
- Не выдумывай цифры, даты, имена.

## ШАГ 3. СЦЕНАРИЙ С ПОКАДРОВЫМИ ТАЙМКОДАМИ
Напиши сценарий на английском в жанре/ритме эталона на тему `{{НАЗВАНИЕ}}`.

**Формат каждого кадра:**
```
[0:00] <english voiceover for this shot>
       (IMAGE: <тип>, краткое описание кадра на русском — что в кадре, движение камеры/действие, ключевой объект)
```

**Тип кадра указывай в начале (IMAGE):**
- по умолчанию — **фотореал-стилл** с движением камеры (push-in / pan / parallax);
- `[AI-видео]` — живой клип 3–6 сек, только для hero-моментов (штормы, вода, огонь, поезда, эрозия). Держи ≤ ~18 на ролик;
- `[карта]` — анимированная карта/инфографика (рельсы огибают город, счётчики, таймлайны, залив наползает). Это фактологический edge.

**Правила таймкодов:**
- Темп озвучки ~2.5–3 слова/сек.
- Меняй картинку каждые 2–4 сек: на рассуждениях реже, на перечислениях фактов/цифр чаще.
- Накопительный реальный тайминг (0:00, 0:03, 0:06…), не порядковые номера.
- Открывай интригу №1 в хуке, закрывай её в финале.

**Структура ролика:**
- **Хук (0:00, без интро):** знакомая посылка → резкий разворот → петля интриги + тизер №1.
- **Обратный отсчёт N→1**, нарастание драмы; самый сильный кейс на №1.
- **Каждый пункт:** бейдж номера → крючок → подъём → крах → остаток сегодня → мост-клиффхэнгер к следующему.
- **Финал:** CTA «напиши свой город в комментах» + петля на следующий ролик.

## ШАГ 4. ПРАВИЛА ТЕКСТА (анти-нейронность) — ОБЯЗАТЕЛЬНО
- Полностью убери «не X, а Y» (not X, but Y) и «Это не просто X, а…» (It's not just X, it's…).
- Не более 2 метафор на весь текст. Не более 2 конструкций-определений «X is Y».
- Уничтожь симметричные предложения и абзацы одинаковой длины.
- Исключи длинное тире (—). Только точка или запятая.
- Запрети лестничный стиль и рваные предложения в 1–2 слова, никаких «No frills. No fluff.».
- Убери общие прилагательные (good, nice, normal, amazing) и искусственные склейки («and here's where it gets…»).
- Вычеркни канцеляризмы: it's important to understand, it's worth noting, in today's world, thus, in the end, at the end of the day.
- Никаких абстрактных выводов без фактов. Пиши живо, на конкретике: даты, числа, имена, места.
- Текст под TTS: пиши «для уха», без труднопроизносимых для синтеза оборотов.

## ШАГ 5. УПАКОВКА (после сценария)
- **3 варианта заголовка** по формуле `[N] [GEO] [Subject] [forbidden clause]` (clause: «They Don't Want You to Find» / «You're Not Supposed to Know About» / «You Won't Believe Are Still There») + выбранный.
- **Концепт превью** в одну строку (разрушенный объект + крупное гео-название + число, тёмный кино-грейд, фирменный ржаво-оранжевый #C8551B, ≤4 слова текста).
- **SEO-описание** (первые 2 строки = хук + ключи) + 12–15 тегов + тайм-коды глав.
- **Закреп-коммент** (тизер №1 + просьба назвать свой город + приглашение к фактчеку).
