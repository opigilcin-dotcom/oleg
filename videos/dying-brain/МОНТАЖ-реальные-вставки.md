- Полный текст + рисунки: PMC — https://pmc.ncbi.nlm.nih.gov/articles/PMC8902637/

- Бери **Figure 1 / Figure 2** (графики ЭЭГ-спектра и волн вокруг момента остановки сердца).

**Куда поставить:** на словах «**Instead, they saw a storm**» — это блок 2, ~**1:28–1:33**. Показать реальный график 2–3 сек, затем вернуться к нашему стилизованному кадру всплеска (frame 05/EEG).

**Как подписать (наложить текст в монтаже):** мелким снизу —

Это и атрибуция (требование лицензии), и сигнал «реальная наука».

**Юридически:** CC-BY разрешает использование при указании авторства. Подпись выше закрывает требование. ✅

## 📝 Текстовые наложения (картинки у нас БЕЗ текста — всё пишем в монтаже)
Накладывай в CapCut поверх чистых кадров. Шрифт — жирный рукописный/маркерный, красный для акцентных слов.

| Тайм-код | Текст на экране |

| 0:40 | THE LAST 7 MINUTES (титул) |
| 1:01 | 2022 |
| 1:14 | −30s … 0 … +30s (на ленте ЭЭГ) |
| 1:28 | подпись источника (см. Вставка 1) |
| 1:40 | MINUTE 0 |
| 2:00 | +10 SECONDS |
| 2:31 | 2013 |
| 3:37 | 2023 |
| 4:20 | (твист — без текста, голос ведёт) |

> Принцип: текст добавляем поверх — так буквы всегда правильные (z_image их рисует криво, поэтому кадры мы делали чистыми).
