# Таблица доходов и расходов — 2026

Файл: `доходы-расходы-2026.xlsx`

## Как загрузить в Google Таблицы
1. Google Sheets → Файл → Импорт → Загрузить → выбрать `доходы-расходы-2026.xlsx`.
2. Вариант импорта: **"Создать новую таблицу"** (Create new spreadsheet) — сохранит все листы и формулы.
3. Google Sheets сам пересчитает все формулы при открытии — ничего дополнительно делать не нужно.

## Структура
- **Сводка** — сводная таблица по всем 12 месяцам сразу (доход, расход, прибыль, разбивка по категориям), полностью автоматическая, тянет данные с листов месяцев.
- **Январь … Декабрь** — по одному листу на месяц. На каждом:
  - Таблица **ДОХОДЫ** — дата, источник (объект), сумма.
  - Таблица **РАСХОДЫ** — дата, категория (выбор из списка), описание, сумма.
  - Автоматический подсчёт: итого доходы, итого расходы, разбивка расходов по категориям, прибыль/убыток за месяц.

## Категории расходов (уже вшиты в выпадающий список)
Аудит, Аренда офиса, Бензин, Телефонная связь, Расходники, Прочее.
Если нужна другая категория — допиши её в список: выдели ячейку в столбце «Категория», Данные → Проверка данных → добавь свой вариант в список.

## Как пользоваться
- **Жёлтые ячейки** — сюда вносить свои данные.
- Всё остальное (белые ячейки с формулами, оранжевые итоговые строки) — считается само, не трогать руками.
- В листе «Январь» уже стоит **1 строка-пример** дохода и 3 строки-примера расходов (помечены «пример — сотрите») — сотри их перед тем, как вносить реальные данные.
- Расход "объектов"-дохода считается общей суммой (без разбивки по каждому объекту) — просто вписывай отдельные поступления в таблицу ДОХОДЫ построчно, они сами суммируются.

## Если нужно больше строк
Если строк под доход/расход не хватило в конкретном месяце — просто вставь новые строки ВНУТРИ существующей таблицы (не после итоговой строки), формулы SUM/SUMIF автоматически захватят их, если вставлять именно между шапкой и итоговой строкой.
