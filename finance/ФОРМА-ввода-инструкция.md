# 📋 Форма быстрого ввода дохода/расхода → автоматически падает в таблицу

Занимает ~5 минут ручной настройки один раз. Дальше — просто открываешь форму (можно с телефона), выбираешь тип/дату/сумму/категорию, жмёшь Submit — строка сама появляется в нужном месяце нашей таблицы `доходы-расходы-2026.xlsx` (уже загруженной в Google Таблицы).

---

## Шаг 1 — Создать форму

1. В своей Google Таблице (той, куда импортировал `доходы-расходы-2026.xlsx`) открой **Вставка → Форма** (Insert → Form). Это сразу создаст форму, привязанную к этой же таблице.
2. Назови форму, например: **«Доходы и расходы — быстрый ввод»**.

## Шаг 2 — Вопросы формы (скопируй тексты один в один — это важно для скрипта)

**Вопрос 1** (обязательный):
- Текст: `Тип записи`
- Тип: **Из списка (multiple choice)**
- Варианты: `Доход`, `Расход`
- Внизу вопроса включи **«Перейти в раздел в зависимости от ответа»** (Go to section based on answer):
  - `Доход` → Раздел 2 (Доход)
  - `Расход` → Раздел 3 (Расход)

**Раздел 2 «Доход»:**
- Вопрос: `Дата дохода` — тип **Дата**
- Вопрос: `Источник / объект` — тип **Текст (короткий ответ)**
- Вопрос: `Сумма дохода` — тип **Текст (короткий ответ)**, Validation → Number
- В конце раздела: «После этого раздела перейти к» → **Submit form**

**Раздел 3 «Расход»:**
- Вопрос: `Дата расхода` — тип **Дата**
- Вопрос: `Категория расхода` — тип **Из списка (dropdown)**, варианты ровно:
  ```
  Аудит
  Аренда офиса
  Бензин
  Телефонная связь
  Расходники
  Прочее
  ```
- Вопрос: `Описание расхода` — тип **Текст (короткий ответ)**
- Вопрос: `Сумма расхода` — тип **Текст (короткий ответ)**, Validation → Number

## Шаг 3 — Убедиться, что ответы падают в ту же таблицу

Вкладка **Responses (Ответы)** формы → значок Google Sheets вверху → **Select response destination** → **Select existing spreadsheet** → выбери `доходы-расходы-2026`. Появится новый служебный лист "Form Responses 1" (это нормально, можно скрыть его позже — сам скрипт берёт данные не из него, а через триггер on submit).

## Шаг 4 — Вставить скрипт

1. В таблице открой **Extensions → Apps Script**.
2. Удали содержимое по умолчанию, вставь код из файла `apps-script.gs` (прислан отдельно).
3. Сохрани (значок дискеты).

## Шаг 5 — Подключить триггер (без этого скрипт не сработает)

1. В Apps Script слева — значок **часов** (Triggers).
2. **Add Trigger**:
   - Choose function to run: `onFormSubmitHandler`
   - Choose deployment: Head
   - Event source: **From spreadsheet**
   - Event type: **On form submit**
3. Save → появится запрос на разрешения (Google спросит, доверяешь ли ты этому скрипту) → **Allow** (это твой собственный скрипт в твоей же таблице, это безопасно).

## Готово — как пользоваться

- Открываешь ссылку на форму (можно сохранить как ярлык на телефоне).
- Выбираешь Доход или Расход → дальше поля появляются сами (ветвление).
- Жмёшь Submit — новая строка появляется в нужном листе месяца (определяется по дате, которую ты указал), прямо над строкой "ИТОГО", формулы автоматически её подхватывают.

## Если что-то не сработало
- Проверь точное совпадение текстов вопросов формы с тем, что в `apps-script.gs` (`getValue(responses, "Дата дохода")` и т.д. — если названия не совпадут хоть на символ, скрипт не найдёт нужное поле).
- View → Executions в Apps Script покажет, было ли исполнение и с какой ошибкой, если строка не появилась.
