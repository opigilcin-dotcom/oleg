# 🚀 МОЩНЫЙ ПЛАН: faceless/AI-канал → реальный бизнес

## 0. Тезис
Канал — это НЕ продукт, а **верх воронки**. Деньги = **recurring-аффилиат + свой цифровой продукт**; AdSense — лишь база. Оптимизируем не «просмотры», а **ценность одного зрителя**. 100k просмотров в покупательской нише > 1M в развлекательной.

## 1. Ниша (рекомендация)
**«AI + продуктивность для соло-предпринимателей / креаторов / фрилансеров»** — аудитория-ПОКУПАТЕЛЬ, recurring-аффилиат, естественный свой продукт (шаблоны/промпты/курс), мы сами в теме, вечнозелёные углы.

## 2. Формат (ПО ДАННЫМ конкурентов — поправлено)
**Faceless: AI-голос + РЕАЛЬНЫЕ скринкасты инструмента + AI-графика/персонаж + сабы.** Это модель TheAIGRID (395K).
- ❌ **AI-аватар-ведущий ВРЕДИТ** в этой нише: среди 121 канала ни один аватар-канал не выигрывает; аудитория AI палит синтетику = «контент-ферма» = убитое доверие (а доверие = продажи продукта). Аватар максимум 3-сек интро, НЕ ведущий.
- ⚠️ **Скринкаст обязателен:** топ-туториалы вывозят реальные демо инструмента на экране. Это единственное, что Claude не делает — водишь инструмент сам (10 мин записи/ролик).
- Хук → лид-магнит (первые 30 сек) → «ошибка» → скринкаст по главам → аффилиат в середине → CTA на продукт в конце.

## 3. Денежный стек (5 потоков)
1. **AdSense** — база (~$6 RPM).
2. **Recurring-аффилиат** с 1-го ролика: Notion (~50%), Jasper (25–30%), ElevenLabs (~22%), Make/Zapier (20–30%), Pictory/InVideo, HeyGen (партнёрка). 1 сигнап = $/мес бесконечно.
3. **Свой продукт** (с ~2 мес, маржа 90%): Free лид-магнит → email; $19–29 «AI Starter Kit» (Notion-шаблоны + промпт-пак + гид); $49–99 мини-курс; (позже) комьюнити Skool (recurring).
4. **Email-лист** с 1-го дня — актив, продаёт что угодно потом.
5. **Спонсоры** с ~4 мес (AI-стартапы/SaaS) — читка 30 сек в сценарий.
6. (Опц.) флип канала за 20–40× месячной прибыли.

## 4. Воронка
Видео → описание/закреп (аффилиат + **бесплатный лид-магнит**) → email-лист → продукт $19–29 → апселл (курс/комьюнити).

## 5. Роли
**Claude (я):** web-поиск актуальных инструментов + валидация тем; сценарии + упаковка + аффилиат-блок; озвучка + кадры персонажа + графика + .bat; **сам продукт** (шаблоны/промпты/структура курса); лид-магниты + email-цепочки + тексты Gumroad; сценарии под аватар.
**Ты:** прогон сценария через аватар-сервис; 5–7 скринкастов; монтаж CapCut + загрузка; регистрация в партнёрках + Gumroad + email-сервис; ритм 2–3 видео/нед.

## 6. 90-дневная карта
- **Нед 1:** фикс ниши → бренд (имя/хендл/аватар-персона) → 5–8 партнёрок → Gumroad + email + аватар-сервис.
- **Нед 1–2:** первые 3 видео; включить захват email.
- **Мес 1:** 8–12 видео, ищем рабочую упаковку.
- **Мес 2:** запуск продукта $19–29, пушим в каждом ролике.
- **Мес 3:** мини-курс $49–99; аутрич спонсорам.
