# 💵 МОНЕТИЗАЦИЯ YouTube — чеклист (гражданство РФ, проживание Таиланд)

> Главное правило: **гражданство роли не играет — важна страна в платёжном профиле.** Google отключил монетизацию для аккаунтов из России (с 2022). Значит, всё оформляем на **Таиланд**. Это рабочий, легальный путь. Нигде не указываем Россию в платёжке.

---

## ЭТАП 0 — что подготовить ЗАРАНЕЕ (можно уже сейчас, до порога)
- [ ] Google-аккаунт для канала (отдельный, не личный российский — чище).
- [ ] В канале: **Настройки → Канал → Расширенные настройки → Страна проживания = Thailand.**
- [ ] Реальный **тайский адрес** (куда придёт письмо с PIN от Google для верификации). Свой, друга, кондо — любой, до которого дойдёт почта.
- [ ] Способ выплат (см. Этап 3) — открыть заранее, чтобы не терять время потом.
- [ ] 2FA на Google-аккаунт (без него YPP не подключить).

---

## ЭТАП 1 — пробить порог YouTube Partner Program (YPP)
Монетизация не включится, пока не выполнено ОДНО из:
- [ ] **1000 подписчиков** + **4000 часов** просмотра long-form за последние 12 мес, ИЛИ
- [ ] **1000 подписчиков** + **10 млн просмотров Shorts** за 90 дней.
- (Ранний уровень YPP — с **500 подписчиков** даёт фан-фандинг/Super Thanks, но полноценная реклама только с 1000.)

➡️ Наша стратегия под это: long-form + резать Shorts из каждого видео (Shorts гонят подписчиков и часы).

---

## ЭТАП 2 — подать заявку в YPP + создать/привязать AdSense
- [ ] YouTube Studio → **Заработок (Monetization)** → подать заявку, как порог пройден.
- [ ] Принять условия YPP.
- [ ] Создать/привязать **AdSense** и **AdSense for YouTube** платёжный профиль.
- [ ] Страна платёжного профиля = **Thailand** (❗НЕ Russia — иначе выплаты заблокированы навсегда).
- [ ] Дождаться проверки канала (обычно до ~месяца).

---

## ЭТАП 3 — способ выплат в Таиланде (выбрать ОДНО)
Порог первой выплаты — **$100** (накапливается, не сгорает).

**Вариант A — Wise (проще всего для нерезидента):**
- [ ] Открыть аккаунт Wise, получить мультивалютные реквизиты (USD).
- [ ] Вставить эти реквизиты в AdSense как банк для выплат.
- [ ] Плюс: не нужен тайский банк/виза. Минус: комиссии на конвертацию.

**Вариант B — тайский банковский счёт (надёжнее всего):**
- [ ] Открыть счёт в тайском банке (Kasikorn/SCB/Bangkok Bank).
- [ ] Обычно нужна долгосрочная виза (не туристическая) + иногда work permit / подтверждение адреса.
- [ ] Вставить реквизиты в AdSense.

**Вариант C — Payoneer** — тоже принимается AdSense, как запасной.

---

## ЭТАП 4 — налоговая форма (обязательно, ~2 минуты)
- [ ] AdSense → **Payments → Settings → Manage tax info → US tax info.**
- [ ] Заполнить **W-8BEN** (для физлица-нерезидента США).
- [ ] Страна налогового резидентства = **Thailand.**
- [ ] Указать тайский **TIN** если есть (не всегда обязателен) — тогда действует налоговый договор Таиланд–США → меньше удержание с дохода от американских зрителей.
- [ ] ⚠️ Договор Россия–США **приостановлен** → указывать РФ невыгодно и неверно. Таиланд корректнее и выгоднее.

---

## ЭТАП 5 — верификация личности и адреса
- [ ] Верификация личности (документ — загранпаспорт РФ подойдёт как удостоверение).
- [ ] Верификация адреса: Google пришлёт **PIN по почте** на тайский адрес (или попросит документ с адресом). Ввести PIN в AdSense.
- [ ] После этого выплаты разблокируются.

---

## 🚩 Частые ошибки (не делать)
1. ❌ Ставить **Россию** в стране платёжного профиля — блок выплат.
2. ❌ Использовать российскую карту/банк для выплат — не пройдёт.
3. ❌ Указывать РФ в налоговой форме — потеря льготы по договору + несоответствие адресу.
4. ❌ Несовпадение страны канала / AdSense / способа выплат — держать везде **Thailand.**
