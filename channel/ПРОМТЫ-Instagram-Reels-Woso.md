**Клипы (каждый 5 сек, загружаем референс):**

## ✅ Правила, которые делают из генерации вирусный Reel

1. **Первая секунда = самый странный кадр.** Никаких заставок.
2. **Текст на экране** в первые 1–2 сек (вопрос / «POV» / «Imagine…»). Пиши его в Instagram/CapCut.
3. **Луп:** конец похож на начало, тогда ролик досматривают по 2–3 раза.
4. **Звук:** трендовый трек из библиотеки Instagram поверх (громкость генерации ниже).
5. **CTA «Comment PROMPT»** + автоответ в директ (ManyChat). Это главный механизм роста аккаунтов про AI: комменты поднимают охват, а в директе ты собираешь базу.
6. **Серии:** Part 1/2/3, Day 1/2/3. Подписываются ради продолжения.
7. **Отметка «AI-generated»** при публикации (Instagram требует метку для реалистичного AI). Без неё могут урезать охват.
8. **Частота:** 1–2 Reels в день, 1 формат = минимум 3 попытки, прежде чем делать вывод.

# 🧠 ТЕКСТОВЫЕ ПРОМТЫ: как заставить чат-нейросеть (в Woso) сделать всё за тебя

> Открываешь в Woso **чат** (ChatGPT / Claude / Gemini, что есть в списке), вставляешь промт ниже, вместо `[...]` пишешь своё **по-русски**. Чат выдаёт готовые промты на английском, их копируешь в генератор видео или картинок.

## Т1. Универсальный генератор видео-промтов (главный, сохрани)
```
Ты — профессиональный промт-инженер для AI-видео (Kling, Seedance, Veo, Runway).
Моя идея (по-русски): [опиши идею, например: «кот-космонавт впервые видит Землю из иллюминатора»].
Формат: вертикальное видео 9:16 для Instagram Reels, длина [5/10] сек.

Сделай:
1. 3 варианта промта на английском по формуле: камера/ракурс + кто + действие + где + свет + движение камеры + стиль + звук. Каждый не длиннее 80 слов. Одно главное действие на клип.
2. В конце каждого промта добавь: no text, no subtitles, no watermark.
3. Под каждым вариантом — одна строка по-русски: чем он отличается.
4. Посоветуй, какая модель лучше подойдёт (Kling — движение и физика, Seedance — один персонаж в разных сценах, Veo — реализм, речь и звук).
```

## Т2. Разбор чужого вирусного ролика → свой промт
```
Я опишу вирусный Reels, а ты сделай из него промт для AI-видео, чтобы я снял похожий, но не копию.
Описание ролика: [что происходит по секундам, например: «0–2 сек: огромная рука над крошечными людьми в пустыне; 2–6 сек: рука поливает их водой из губки; люди радуются»].
Дай:
1. Почему он залетел (хук, эмоция, луп) — 3 пункта.
2. Промт на английском для повторения механики, 9:16, 5–10 сек.
3. 5 вариантов той же механики с другим сюжетом (по одной строке по-русски + промт на английском).
```

## Т8. Почини промт, если генерация вышла плохо
```

```
