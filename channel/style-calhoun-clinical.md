# 🎨 Стиль «Clinical» (по разбору Zenn «The Calhoun Effect», 3.8M / 2.58% лайков)

Снято с реального видео через мультимодальный разбор. Это эволюция нашего whiteboard — «немного поменяли»: тот же минимализм, но клиническая палитра и тревожное настроение.

## Что увидели в Calhoun
1. **Арт:** минималистичная 2D рисованная иллюстрация. Чистый РАВНОМЕРНЫЙ чёрный контур, плоская заливка. Без теней, градиентов, 3D. Стиль explainer-вебкомикса / whiteboard.
2. **Палитра:** приглушённая «клиническая» — бежевый, тёплый серый, коричневый, кость, белый. Высокий контраст к фону. **Красный — ТОЛЬКО для акцента** (текст, точка-данные, один объект). Видно на 00:22, 01:09.
3. **Персонажи:** люди — простые стикмены с минимумом черт. Объекты — округлые формы, точки-глаза, тонкие линии. Деталей — минимум для узнавания.
4. **Композиция:** разреженная, геометрическая. МНОГО негативного пространства. Центрирование или простая изометрия для «коробки»/комнаты.
5. **Текст на экране:** жирный рукописный sans-serif. Таймкоды/ярлыки — в правом верхнем углу; крупные заголовки — по центру.
6. **Движение:** простые пан/зум/слайд. Без сложной 3D-камеры и параллакса.
7. **Тон:** клинический, отстранённый, образовательный — и подспудно тревожный за счёт контраста простого рисунка и тёмной темы. ← ВОТ ЭТО и есть «секрет» Calhoun.

## Упаковка по эталону Calhoun (внедрить в видео)
- **Заголовок** = загадка/любопытство, не описание (у нас компиляция → «Every Glitch in Your Brain» в духе Brainosophy 1.58M).
- **Теги** = ПОИСКОВЫЕ слова (название каждого эффекта), а не бренд-заголовок.
- **Описание:** тёмный хук-история → «большинство думает X, но правда темнее» → под-темы с интригующими терминами → **зеркало на зрителя** → вопрос-приманка в комменты → блок **SOURCES** (реальные статьи) → 5 хэштегов.
