# Лендинг-лид-магнит «Пак промтов для AI-видео»

Один файл `index.html`, без сборки и зависимостей.

## Запуск
- Локально: открыть `index.html` в браузере.
- Бесплатный хостинг: GitHub Pages (Settings → Pages → папка `/landing`), Netlify Drop или Cloudflare Pages.

## Что настроить (блок `CONFIG` в конце файла)
- `FORM_ENDPOINT` — адрес, куда уходит почта (POST, JSON `{email, source}`). Подойдут Formspree, Getform, Make/Zapier-webhook или форма вашей рассылки (MailerLite, Brevo и т.п.). Пока пусто, работает демо-режим: контент открывается, но почта нигде не сохраняется.
- `FREE_COUNT` — сколько промтов открыто без почты (по умолчанию 3).
- Название бренда: «AITrendLab» в шапке и `<title>`.
- Тексты и промты — массивы `VIDEO` и `CHAT`.

## Важно
- Замок на контент работает на стороне браузера: человек, который откроет код страницы, увидит промты без почты. Для лид-магнита это нормально. Если нужна настоящая закрытость, отправляйте промты письмом после подписки.
- Подтверждение подписки (double opt-in) и ссылку на отписку обеспечивает сервис рассылки.
- Если соберёте почты из ЕС/РФ, добавьте ссылку на политику конфиденциальности и согласие на рассылку (чекбокс) в соответствии с местным законом.
- Для связки с Instagram: в био ссылка на этот лендинг, в Reels призыв «комментарий PROMPT → ссылка в директ».
