## Сборка
```bash
npm install
python3 prep.py          # скачивает ассеты из config.sources, шрифты (Caveat, PT Mono), синтезирует музыку+SFX -> public/mix.wav
npx remotion render src/index.ts DeskReel out/raw.mp4 --crf=18
ffmpeg -i out/raw.mp4 -c:v copy -af loudnorm=I=-14:TP=-1.5:LRA=11 -c:a aac -b:a 192k out/final.mp4
```
